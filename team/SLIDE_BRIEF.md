## 一、先说清楚：官方到底要求什么

我翻过官方的全部文件（Domain 1 说明、提交模板、参赛指引），结论是：

> **官方没有规定幻灯片页数、模板和时长。**
> 它只在 README 的 Links 表里要求一个 **`Slide Deck` 链接**，和提交时要一并给出。

所以要求不是"套官方模板"，而是：**让评委在 5 分钟内听懂我们在解决什么问题、怎么解决、凭什么能做出来。**

评分标准（这才是真正的"要求"）：

| 维度 | 权重 | 评委会看什么 |
|---|---|---|
| **创新与创意** | **30%** | 问题切片是否锐利（**具体用户 + 具体需求时刻**）；方案是否超越"传个简历问聊天机器人" |
| **问题-方案契合度** | **25%** | 是否覆盖完整链条：追踪 AI 进展 → 预测兴起/衰退技能 → 人岗匹配 → 个性化路径 → SDG 连接；**6 个必备功能**是否都讲清楚 |
| **可建造性** | **25%** | 核心功能真能跑（现场演示）+ GitHub 仓库支撑；**主动点名最大风险**并给出对策 |
| **表达清晰度** | **20%** | 结构 = 问题 → 方案 → 预期结果；外行听一遍能复述"用户是谁、拿到什么" |

**关键**：初赛不需要成品，需要"**提案 + 一个能跑的核心功能**"。所以幻灯片里**必须有一页是真实截图**，不能全是示意图。

## 三、逐页大纲（照着填）

### 第 1 页 · 封面
- 大标题：**SkillRadar MY**
- 副标题：把 AI 趋势翻译成"你下一步该学什么"
- 底行：Lumina Nusantara · Domain 1 · SDG 4（主）· SDC 2026 初赛
- 视觉：深色渐变或 App 首屏截图虚化

### 第 2 页 · 问题（30 秒，"锐利切片"）
**标题**：不是"AI 会取代人"，而是"没人告诉你该学什么"

三个数字（**必须原样引用，有出处**）：

| 数字 | 出处 |
|---|---|
| 马来西亚 **56%** 专业人士已在工作中使用 AI，但仅 **26%** 受过正式培训 | Hays Asia Salary Guide 2025 |
| **60 万+** 工人需在 3–5 年内再培训 | 马来西亚科技与创新部（MOSTI） |

**具体用户**（这是拿创新分的关键，别写"所有人"）：
- 被 AI 冲击的在职者：35 岁、6 年经验、岗位正在被自动化
- 应届生：有学历、没方向
- HR / L&D：不知道该先培训谁
- 就业中心 / TVET：课程和岗位需求脱节

**一句话**：现有工具要么给"技能清单"（过期即废），要么给"聊天机器人"（不可核查）。

### 第 3 页 · 方案总览（一图流）
**标题**：四步，从"我现在会什么"到"我下一步学什么"

```
① 描述自己  →  ② 看趋势雷达  →  ③ 拿到匹配岗位  →  ④ 拿到学习路径
 （问卷/CV）      （官方数据）      （可解释评分）      （真实课程）
                                        ↓
                                  每个岗位都挂 SDG
```

**重点标一句**：全程 **不调用大模型**，规则可复现、可审计。

### 第 4 页 · 趋势层（这是"可建造性"的核心，评委最想看这个）
**标题**：趋势不是猜的，是官方数字 + 明确标注的推导

**双层结构**（截图用 `team/screenshots/final-trend.png`）：

| 层 | 内容 | 性质 |
|---|---|---|
| **第一层** | DOSM《Job Market Insights》2025 Q2：在线招聘 **281,736** 条（环比 **+7.1%**）；技术与辅助专业人员 **63,803**（**+50.5%**） | **官方数据**，附发布日期 2026-02-26 与原文链接 |
| **第二层** | 报告明确点名的高需求领域：应用 AI、软件开发、网络安全、数据分析 → 映射到具体技能 | **推导**，每张卡都写明依据 |

**必须说的一句话**（评委一定追问）：
> 职业招聘数量是**代理指标**，不是技能需求的直接证明；我们在界面上明确标注了这一点，并且第二层只使用报告**直接点名**的技能，不编造百分比。

来源：Jobstreet by SEEK / Randstad，经 [The Edge Malaysia 2026-02-04](https://theedgemalaysia.com/node/791561) 报道。

### 第 5 页 · 匹配与可解释评分
**标题**：每个推荐分数都能拆开看

公式（照抄）：

```
score = 0.30×技能覆盖 + 0.25×岗位聚焦 + 0.15×可迁移性
      + 0.15×需求趋势 + 0.15×(1−缺口成本)
```

- 技能分三档权重：核心 1.0 / 重要 0.6 / 加分 0.3
- 覆盖不全就不给高分：**覆盖 68% 时不会说"你很接近"**（截图 `coverage-explained.png`）
- 规模：**45 个岗位 / 9 个领域 / 46 个专业 / 71 个技能标签**

### 第 6 页 · 学习路径 + SDG
**标题**：不只告诉你缺什么，还告诉你去哪学、多久

左：学习路径表（技能 → 周数 → **已核实的真实课程**，如 Coursera Google Data Analytics 180h 免费旁听 / freeCodeCamp SQL 20h 免费）
右：SDG 环形图（截图 `sdg-wheel.png`）+ 说明"主 SDG 4，相关 4.4 / 4.3 / 8.2 / 8.5"

**强调**：课程是**已核实可访问的真实链接**，不是 AI 生成的假课程。

### 第 7 页 · 现场演示（放真实截图，最好 2–3 张拼图）
- 三入口：求职者（在职 / 应届）、HR / L&D、就业中心 / TVET
- 三语言：English / Bahasa Malaysia / 中文（截图 `landing-zh.png`、`landing-ms.png`）
- 截图：`landing.png`、`intake.png`、`merged-results.png`、`skill-search.png`

### 第 8 页 · 我们主动点名风险（25% 那栏最容易被扣分的地方）
**标题**：我们最担心什么，以及怎么兜底

| 风险 | 我们的处理 |
|---|---|
| 趋势数据可靠性 / 可更新性 | 只用官方公开数据，界面标注来源与日期；数据文件独立，季度可替换 |
| 匹配质量 | 评分规则透明、可复现；不宣称是录用概率 |
| AI 编造岗位/课程 | **推理阶段不调用任何大模型**；岗位库为团队整理并注明"非官方抽取"；课程逐条核实链接 |
| 数据合规 | 只用公开数据与合成简历，不收集真实个人数据 |

### 第 9 页 · 与 6 个必备功能的对应（评委逐条打勾的地方）
做成一张**打勾表**，左边写官方 6 条，右边写我们怎么实现：

| 官方必备功能 | 我们的实现 |
|---|---|
| 1 技能档案录入 | 问卷（65 项技能 / 11 分类 + 跨分类搜索）或合成 CV 上传 |
| 2 AI 趋势信号层 | DOSM 2025 Q2 官方数据 + 报告点名的技能方向，均标来源与日期 |
| 3 未来岗位匹配 | 可解释加权评分 + 技能缺口分解 |
| 4 个性化再培训路径 | 排序学习计划 + 已核实课程与时长 |
| 5 SDG 映射 | 每个岗位挂 SDG，三语言 SDG 环形图 |
| 6 不确定性处理 | 温和 / 快速两种 AI 冲击情景（⚠️ 见下方"待确认"） |
