# Archived data (not used by the app)

These files were superseded by `data/trends/dosm_q2_2026.json` and the curated catalogue in
`data/`. They stay in the repository for history only. **Nothing in the running application reads
them**, and none of them is evidence of the Malaysian labour market.

| File | What it was | Why it is here |
| --- | --- | --- |
| `experimental.json` | Early placeholder catalogue with arbitrary weights | Superseded by `data/roles.json`; its weights were never used |
| `derived_latest_q2_2025.json` | Skill directions derived from the 2025 Q2 snapshot | Superseded; the app now reads the dated 2026 snapshots directly |
| `dosm_q2_2025.json` | DOSM 2025 Q2 transcription | Kept only as the previous-quarter reference used when the 2026 file was built |
