# 一键启动与部署（Replit）

## 最简单的方式：点 Run

仓库里已经配好了 `.replit`，**打开 Repl 后直接点顶部的 ▶ Run 按钮即可**：

```toml
run = "python -m streamlit run app.py --server.port 5000 --server.address 0.0.0.0 --server.headless true"
entrypoint = "app.py"
```

右侧会出现应用界面，不需要任何手动操作。

---

## 如果你喜欢在 Shell 里敲命令

```bash
python app.py
```

`app.py` 自带自动修复：

1. 检查 Streamlit 是否安装
2. 没装就自动 `pip install streamlit pandas`（只跑一次）
3. 然后自动以正确端口启动，不需要再记 `streamlit run` 参数

验证（本机已跑通）：

```
HEALTH b'ok'
ROOT HTTP 200
```

---

## 报 "ModuleNotFoundError: streamlit" 怎么办

三个办法，任选其一：

| 办法 | 操作 |
| --- | --- |
| **A（推荐）** | 重开一次 Repl，让 Replit 重新读取 `.replit` |
| **B** | 在 Shell 里执行 `pip install -r requirements.txt`，再点 Run |
| **C** | 在 Shell 里执行 `python app.py`（自带安装逻辑） |

> 根目录 `requirements.txt` 现在**只保留 `streamlit` 和 `pandas`** 两个包。
> `runpod` 已挪到 `runpod/requirements.txt`——它是给 RunPod 那边的镜像用的，
> 装在网页应用里既慢又容易报错，所以移走了。

---

## 端口说明

| 环境 | 端口 | 说明 |
| --- | --- | --- |
| Replit | 5000 | `.replit` 里写死，Replit 会把 5000 映射到外网 80 |
| 本地 | 8501 | Streamlit 默认 |
| 其它 | `PORT` 环境变量 | `PORT=9000 python app.py` |

---

## 常见报错对照

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'streamlit'` | 依赖没装 | 见上面三条 |
| `ModuleNotFoundError: No module named 'utils'` | 路径问题 | 确认用 `python app.py`（从根目录跑），不要 `cd src` 再跑 |
| 右侧预览空白 | 端口没对上 | 确认 `.replit` 里是 5000，且 Replit 的 Webview 指向 5000 |
| `Address already in use` | 端口被占 | 改 `.replit` 里的 `--server.port 5001` |
| `runpod` 相关报错 | 不该装它 | 已从根目录 `requirements.txt` 移除 |
