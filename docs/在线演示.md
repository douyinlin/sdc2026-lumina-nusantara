## 演示流程（90 秒）

1. 打开上面的链接，右上角可切换 **English / Bahasa Malaysia / 中文**
2. 左侧 **Upload a CV** → 拖入 `data/sample_cv.txt`（合成示例简历）
   → 系统识别 9 项技能并自动填入
3. 左侧 **Scenario** 选 Fast disruption，观察排名变化
4. 主区域查看：
   - **Future Skills Radar** — 每条趋势带 Source 和 Retrieved 日期
   - **SDG contribution** — 候选岗位覆盖的 SDG 标签
   - **Ranked future roles** — 展开任一岗位看 4 个分量的拆解
   - **Your reskilling pathway** — 由易到难的周计划
   - **Comparison across scenarios** — 温和 vs 快速两种情景的分数对比
5. 底部声明：本工具辅助人类做职业决策，不替代人的判断

## 本地运行（备用）

双击仓库根目录的 `启动 SkillRadar.bat`，或命令行：

```bash
pip install -r requirements.txt
streamlit run app.py
```

默认地址 `http://localhost:8501`。

## 已知限制

- 趋势数据当前为**种子快照**（`data/trends/latest.json`），演示前应替换为真实抓取结果
- PDF 简历解析为轻量实现，扫描版或特殊字体的 PDF 可能识别不到，可改用 `.txt`
- Free 版实例在长时间无访问后会休眠，首次打开需要 30–60 秒唤醒
